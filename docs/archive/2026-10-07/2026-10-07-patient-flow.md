# 患者主流程实施与验收

依据：用户 2026-10-07 实施授权；0716 会议、0717 业务流程；最终三医接口 v1.0.1；V2.2；现有 9+6+35 表实库。当前基线 2087013。旧测试代码不作为代码基础。

## 目标和边界

患者变化先静默准备，挂件打开读取当前 context；展示疾病/病理候选、原始证据和独立提示；查看不等于采纳；选用后生成患者实例，在同一完整表单中回填和编辑；保存不可变修订，单独确认；模型仅通过受控工具读取数据，输出有来源的解释和复核发现。

未配置模型密钥和真实院方服务时，功能返回明确配置状态。此次不制作演示患者数据。自动化测试替身只用于合同验证，运行模式必须显式标识，不能计为真实 Agent 或医院调用。

## 冻结的实现决定

- FDA5/CSCO7/I-A 是项目版本化配置；保留来源原生等级。未审核知识不得自动变成已审核。
- V2.2：当前疾病/病理构建候选，普通风险、缺失、分期/线次不降级。只有预配置适应症外关系和明确绝对禁忌进入 X；无关癌种不展示。
- 同等级用方案代码稳定显示；该键只使结果可复现，不赋予临床优先级。未核验证据独立标识，不伪造 VERIFIED。
- Reviewer 手动复核针对已保存的确切修订；确认后异步自动复核，以0717技术V1.2为自动触发基线。是否增加保存后自动触发为后续配置，默认不开。Reviewer 不阻断/撤销医生确认，不覆盖医生内容。
- 医生来源字段、计算字段不能通过编辑覆盖；药物结构性变动只在明确白名单下开放，未确认项保留原值。
- 模型配置仅后端环境变量；不写入浏览器、不提交密钥；SDK不得任意SQL、Shell、文件读写或调用医院写接口。
- 科学家前端参考来源为 /Users/alan/Documents/公司项目代码-医疗AI项目/scientific-agent-platform-frontend；采用紧凑导航、统一层级、细边界、柔和状态过渡，临床数据和表单保持稳定。
