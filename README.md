# 化疗智能体产品工程

本工程新建于 2026 年 9 月 30 日，包含独立的 `backend/` 和 `frontend/`。它不延续此前本地测试代码或历史 PoC；详细边界见 [AGENTS.md](AGENTS.md)。

默认 `/` 是临床入口：只按 `context_id` 读取本次患者的后台准备状态与已保存候选。没有可信上下文时如实等待，不用公共目录代替患者候选。`/catalog` 是独立的方案与证据只读浏览页，展示草稿及待核验状态。当前临床读取合同仅在本机/测试环境、连接**独立测试库**且记录为合成 `TEST_ONLY` 时可用；生产请求拒绝凭 `context_id` 直接读取。见 [项目事实基线](docs/项目事实基线与实现偏差_20260930.md) 与 [本批验收记录](docs/临床入口与测试上下文读取_20260930.md)。

后端：在 `backend/` 执行 `uv sync`、`uv run uvicorn chemo_agent_product.api:app --host 127.0.0.1 --port 8011`。配置示例见 `backend/.env.example`；目录数据库与运行测试数据库必须是不同库。前端：在 `frontend/` 执行 `npm ci`、`npm run dev`，打开 `http://127.0.0.1:5173/`。

`AUTO_PREPARE` 触发、患者快照与候选生成、患者实例保存/确认、真实院方接口和模型服务尚未实现。运行表已建好与业务功能已接通是两件事。
