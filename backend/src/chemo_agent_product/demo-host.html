演示顺序

  1. 选患者甲，等待右下角“候选已就绪”，再打开挂件。
  2. 查看依据、对比方案，选用 BC-001。
  3. 点击“填入本例演示值”，修改一项，再保存、确认。
  4. 查看修订历史、独立复核状态。
  5. 进入“院方交付检查”，模拟预校验、导入、回查、归档、签名回查。
  6. 患者丙演示缺失／过期；患者丁演示部分失败和撤销。
